# Taklif-shartnoma — qisqa qo'llanma

## Agent: shartnoma tuzish

1. **Vrachlar** → vrachni oching
2. **«Taklif-shartnoma»** bo'limida **«📝 Shartnoma tuzish»**
3. Tarifni tanlang (START-10 / RITM-20 / USTA-50 / PROFI-100)
4. Tasdiqlang — **teskari sanoq shu zahoti boshlanadi**

Vrachda ochiq shartnoma bo'lsa yangisi tuzilmaydi. Avval eskisi yopilishi kerak —
bu qarz to'planishining oldini oladi.

**Bosma nusxa:** Shartnomalar → kerakli shartnoma → **«📄 PDF»**. Vrach imzolaydi.

## Buyurtma shartnomaga o'zi bog'lanadi

Ochiq shartnomasi bor vrachga buyurtma yozsangiz, u **avtomatik** o'sha
shartnomaga bog'lanadi — hech narsa tanlash shart emas. Buyurtma sahifasida
📝 belgisi bilan ko'rinadi.

## To'lov qaysi shartnomaga tushadi

Buxgalter to'lov kiritganda tizim uni **muddati eng yaqin** shartnomaga
yozadi (eng eskisiga emas). Sabab: vrach sovg'ani yo'qotmasligi kerak.

## Omborchi: sovg'ani berish

**Shartnomalar → «Sovg'alar»** tabida qozonilgan, lekin hali berilmagan
sovg'alar turadi. «Sovg'ani berdim» bosilganda:

- sovg'a katalogdagi mahsulot bo'lsa — **ombordan yechiladi**
- harakat «Sovg'a» turi bilan yoziladi — sotuv ham, spisaniye ham emas,
  shuning uchun hisobotlar chalkashmaydi

Sovg'a katalogda bo'lmasa (masalan «Chet el safari») — ombor tegilmaydi.

**Sozlash:** Tariflar → tarifni oching → «Sovg'a katalogdagi mahsulotmi?»
ro'yxatidan tanlang. Tanlanmasa ombordan yechilmaydi.
